# 🚀 Raven-modified

A custom, open-source Minecraft utility client for version **1.8.9**, built as a fork of the Raven B++ repository. 

This project is completely free, open-source, and community-driven.

---

## 💾 Downloads & Installation

To run this client, you need **Minecraft Forge for 1.8.9**.

1. Go to the **Releases** tab on the right side of this GitHub page.
2. Download the latest `.jar` file.
3. Drop the `.jar` file into your Minecraft `.minecraft/mods` folder.
4. Launch your game using the Forge 1.8.9 profile.

---

## 🛠️ Developer Setup & Compiling

If you want to build the client from the source code yourself, a **Java 8 installation** is strictly required.

### Windows:
Run `builder.bat` in the root directory to automatically clean and compile the project.

### Mac / Linux:
Open your terminal in the project directory and run:
```bash
./gradlew clean build
```

Once the process finishes, you can find your compiled mod file inside the `/build/libs/` directory.
